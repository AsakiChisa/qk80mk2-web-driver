# QK80 MK2 Web Driver v1.0.0

## v1.0.0 正式版

- 将现有稳定功能整理为首个正式版本。
- 保留 v0.6.6 的安全响应式布局、键位编辑、灯光、Macro、Profile 与 7×7 点阵动画功能。
- 本版本作为后续界面与功能更新的稳定基线。

## v0.6.6 全屏 / 窗口自适应修正版

- 修复 v0.6.5 在最大化、宽屏和窗口化时主键盘被拉伸/偏移/裁切的问题。
- 现在只让外层工作区随浏览器宽度伸展，主键盘仍保持固定物理比例并自动居中。
- 恢复 v0.6.4 的主键盘几何规则和基础按键选择器尺寸，不再根据超宽视口强行放大。
- 2K / 4K / 浏览器缩放场景下，页面会使用右侧空余空间，但不会破坏键盘布局。

## v0.6.4 改键区可读性优化

- 删除界面底部“原始 6×16 Matrix 调试视图”（内部协议 DOM 仍隐藏保留，避免影响既有逻辑）。
- 基础按键的 ATK 风格键盘选择器整体放大，键帽和文字更清楚。
- 增加基础键盘选择区高度，减少拥挤和误点。
- 修复左侧设备卡中键盘图标与 QK80 MK2 文案距离过近的问题。

## v0.6.3 改键体验优化

- “基础”按键池改成标准键盘形状，按键位置与真实键盘一致，更容易查找。
- 媒体 / 宏 / 换层 / 特殊 / 灯光 / 自定义等分类继续保留原来的功能卡片布局。
- 新增改键“撤销 / 恢复”历史栈；没有可撤销/可恢复操作时按钮自动置灰。
- 新增“恢复默认”按钮：安全恢复 Layer 0 的标准基础键位，QK 自定义 Scr 1 / Scr 2 保持不变；该操作本身也可撤销。
- 左侧 QK80 设备图标替换为主题自适应的小键盘图，不再使用黑色“80”方块。

## v0.6.2 本地主题 / 背景系统

- SYSTEM 新增「界面样式」页面。
- 内置 Angry Lime / Chisa Rose / Ocean / Violet Night / Carbon 五套主题。
- 可独立修改整体主色、可视化改键的选中键颜色、页面背景色、面板颜色。
- 支持自动/手动切换深浅文字，以适配自定义深色背景。
- 支持上传 PNG / JPEG / WebP / GIF 作为自定义背景，并可调整 Cover/Contain、位置、可见度和模糊。
- 主题参数保存在当前站点 `localStorage`；背景图片保存在当前站点 `IndexedDB`，不会上传服务器。
- 正式部署后，同一浏览器、同一域名会自动恢复界面样式；清除浏览器站点数据、无痕会话结束或换设备后需要重新设置/上传。
- 背景图单文件限制 25 MB，避免浏览器本地存储占用过大。

## v0.6.0 UI 重构

- 全局改为冷灰工业风界面。
- 新增左侧分组导航：KEYBOARD / LIGHTING / SYSTEM。
- 顶部改为紧凑设备状态栏。
- 连接区、改键、宏、灯光、Profile、设备设置、调试日志统一为扁平化驱动界面。
- 功能协议与 v0.5.1 保持一致，本版主要重构 UI。


## v0.5.1 修复 / 新增

## v0.5.1 HID 串行队列修复

- 修复“读取逐键 RGB”尚未结束时再次点击“写入并保存当前帧”，可能出现 `HID 响应超时`。
- 所有 Raw HID 命令现在统一进入单一串行队列，严格按“发送 → 等待响应 → 下一条”执行，与 QK/VIA 官方驱动的队列模型一致。
- 主键盘 RGB 的读取 / 静态写入 / LED 索引测试增加互斥锁，避免两个长操作同时访问键盘。
- HID 超时信息会额外显示“最近收到”的报文，若仍有协议差异可直接据此定位。


- 宏动作卡片支持从任意动作后手动插入：键盘/鼠标、延时、文本。
- 键盘/鼠标动作可直接点击名称修改 Keycode，并可切换 Tap / 按下 / 松开。
- 延时/文本输入框默认无边框，仅悬停卡片或聚焦时显示编辑框，减少视觉噪音。
- 每张宏动作卡片悬停显示 `＋`，可从中间插入新动作；顶部 `＋ 动作` 用于追加到末尾。



- 宏动作改成紧凑小格布局：同一行可显示多个动作，按序号阅读，减少纵向滚动。
- 新增「导出宏」：导出 M0～Mn 为 `QK80-MK2-Macros-*.json`。
- 新增「导入宏」：载入 JSON 到编辑器缓存，确认后再点「保存全部宏」写入键盘。
- 宏 JSON 保存的是可编辑表达式，便于备份、迁移和人工查看。


- 修复改成 Macro 后键帽下方仍显示旧物理标签（如 `O`）的问题。
- Macro 编辑器改为可视化动作时间线，不再以纯表达式作为主界面。
- 支持逐条删除宏动作，并保留“高级：原始宏表达式”用于调试。
- 录制宏时支持鼠标左键、右键、中键、侧键 1/2（以及浏览器能报告的更多按钮）。
- 支持滚轮上/下/左/右录制。
- 鼠标事件对应 VIA Protocol 12 的 `KC_MS_BTN1..8` 与 `KC_MS_WH_*`。
- 鼠标移动轨迹不会被录制；浏览器只能捕获当前页面/窗口收到的鼠标事件。

## v0.4.1 修复

- 修正 VIA Protocol 12 的高级 Keycode 范围：Macro 改为 `0x7700–0x770F`，Layer 系列改为 v12 范围，QK Custom 改为 `0x7E00+`。
- 修复“宏已写入但把键改成 Macro 后无反应”。
- 可视化键盘主标签现在显示**当前实际映射**；物理位置原始名称降为小字，改键后不再出现“上面还是 O、下面才是 A”的错觉。
# QK80 MK2 Web Driver v0.5.1

第三方实验性网页驱动，针对 QK80 MK2（VID `0x514B` / PID `0x4D02`）。

## v0.4.1 新增

### Macro M0–M15
- 从键盘读取 Macro 数量与 Macro Buffer。
- 编辑 M0–M15 并一次写回键盘。
- 支持 VIA/QMK v11+ 宏格式：
  - `{KC_A}`：点击按键
  - `{+KC_LCTL}`：按下按键
  - `{-KC_LCTL}`：松开按键
  - `{100}`：等待 100 ms
  - 普通 ASCII 文本：直接输入字符
- 提供录制模式，可选择记录按键之间的延时。
- 宏文字流目前只允许 ASCII；中文字符不会直接写入 Macro Buffer。

### Profile 保存 / 加载
导出的 `CHISA QK80 MK2 Profile` JSON 可备份：
- 所有 Layer 键位
- Macro 原始 Buffer
- 氛围灯 / 轴灯 / 点阵屏普通设置
- MAGIC / FEATURES / 当前连接模式
- 当前网页 7×7 点阵编辑器中的帧与 FPS

载入 Profile 后会先显示摘要，点击“应用 Profile”才会写入键盘。
连接模式默认不会恢复，避免导入过程中设备立即掉线；可以手动勾选。
7×7 动画默认只载入网页编辑器，只有勾选对应选项并连接 CDC 才会上传到键盘。

### 设备设置
- MAGIC
  - NKRO
  - Win / GUI 键开关
  - Alt / GUI 互换
  - Caps → Ctrl
- FEATURES
  - LED 总电源
  - 休眠时间
  - Debounce Mode
  - Debounce Delay
- 日期 / 时间同步
- 连接模式
  - USB
  - 2.4G
  - Bluetooth G1 / G2 / G3
  - 清除当前绑定 / 全部蓝牙绑定
  - 2.4G Receiver DFU
- EEPROM Reset
  - 必须输入 `RESET` 再二次确认

这些 Custom Menu channel / ID 来自 QK80 MK2 官方 definition，而不是猜测。

## 已有功能

- WebHID Raw HID 连接
- Web Serial / CDC 连接
- QK80 MK2 可视化物理键盘改键
- Layer 0–3
- 分区 Keycode 功能池与搜索
- 原始 6×16 Matrix 调试视图
- 氛围灯 / 轴灯 / 点阵屏普通设置
- 7×7 HSV888 多帧点阵编辑、预览和 CDC 上传
- CDC 串口占用提示
- HID / CDC 一键断开

## 已确认底层

- Raw HID：Usage Page `0xFF60` / Usage `0x61` / Report ID `0`
- 实机 Protocol：`0x000C`
- Web Serial / CDC：`115200 baud` / `64-byte packet`
- 点阵：`C0/C1`，7×7，HSV888，row-major，56-byte CDC payload
- 灯光：
  - Channel `0x15`：氛围灯 / Underglow
  - Channel `0x16`：轴灯 / RGB Matrix
  - Channel `0x1A`：点阵屏 / Matrix LED
- 普通灯光颜色 Custom Value 使用 Hue + Saturation 两字节；亮度单独存储。

## 启动

Windows 解压后双击：

`start-local.bat`

浏览器访问：

`http://localhost:8080/`

必须使用桌面 Chrome / Edge。

## 连接顺序

1. **关闭 QK 官方网页**，官方网页可能独占 COM 串口。
2. USB 有线连接键盘。
3. 点 `连接 HID`。
4. 如需 7×7 点阵上传，再点 `连接 CDC` 并选择 `QK80 MK2 (COMx)`。
5. 设备设置、Macro、Profile 的大多数功能只需要 HID。

## 建议 v0.4 首轮测试顺序

1. 先点“设备设置 → 读取全部设置”，确认读取值与官方页面一致。
2. 测试 MAGIC / FEATURES 中一个无风险选项。
3. 进入 Macro，先读取，再编辑一个未使用的 M 编号并保存。
4. 导出 Profile，检查 JSON 摘要。
5. 最后才测试连接模式，因为切出 USB 后网页可能立即断开。
6. EEPROM Reset 是破坏性操作，除非确实要恢复配置，否则不要测试。

## 部署

这是纯静态网站。上传 `index.html / app.js / styles.css` 到 Cloudflare Pages、GitHub Pages 或 Nginx 即可；公网必须使用 HTTPS 才能调用 WebHID / Web Serial。

## v0.5.1 主键盘逐键 RGB

- 新增 Per-Key RGB 画板：协议 `CUSTOM_GET/SET [0x00,0x01,LED,0x01,H,S]`。
- 支持读取当前静态色、写入并保存当前帧。
- 支持多帧网页预览与实时 HID 推送；实时模式不执行 SAVE，页面关闭即停止。
- QK80 MK2 官方 definition 当前没有 `li` LED 映射，默认使用画面顺序 0…85，并提供 LED 索引校准/本地保存。
- Per-Key 扩展只有 Hue/Saturation；亮度仍由轴灯全局 Brightness 控制。
