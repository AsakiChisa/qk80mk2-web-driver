# QK80 MK2 Web Driver

QK80 MK2 的本地网页驱动。项目使用原生 HTML、CSS 和 JavaScript，无需安装 npm 依赖。

当前正式版本：**v1.5.0**

## 功能

- VIA/QMK 键位读取与改键
- 宏读取、编辑、导入与导出
- 轴灯、氛围灯和点阵屏普通参数
- 7×7 点阵动画编辑与上传
- 320×172 彩色屏幕图片、GIF / MP4、相册与主题槽上传
- 主键盘 91 灯 RGB 画板
- 多帧 RGB 动画、本地方案和 JSON 导入/导出
- 一键生成自定义呼吸灯和双色流动渐变动画
- 任意按键多选效果范围，以及单包 `MASK_COLOR` 顺滑呼吸/双色渐变
- Profile 导入与导出
- 本地界面主题与背景设置

## 主键盘 RGB

主键盘整帧 RGB 使用已实机验证的 `RAM_FRAME_V2` 私有通道；v1.5.0 另外加入已实机验证的 `RAM_FRAME_V3 MASK_COLOR`：

- 91 颗灯，RGB888，共 273 bytes
- 每帧 `BEGIN → 13 DATA → COMMIT`
- DATA 期间保持上一完整画面，COMMIT 时一次刷新
- 黑色会作为真正的 `[0,0,0]` 发送
- 宽键会自动控制对应的多颗灯
- 默认 4 FPS，10 ms 包间隔
- 冷启动立即播放，实测 4 FPS、超周期帧 0
- 仅写 RAM，不写 EEPROM
- 点击“退出接管”、关闭/刷新页面或重新上电后恢复官方灯效
- V3 每次只发送 12-byte 物理灯掩码和一个 RGB 颜色，未选中的灯保持不变
- V3 顺滑模式已实测稳定达到 30 FPS，无闪烁、卡顿、超时或键盘输入异常

5 ms 在冷启动时会长时间卡顿，0 ms 会直接停滞，因此正式版不提供这两个档位。

## 固件要求

主键盘 91 灯整帧功能要求键盘已经刷入配套的 `RAM_FRAME_V2` Master 和 PLC 固件。按键级顺滑效果只需把 PLC 更新为 `RAM_FRAME_V3 MASK_COLOR` 候选固件；Master 仍使用原来的 V2 版本，无需重复刷写。原厂固件不支持这些私有通道。

其他 VIA/QMK 功能是否可用取决于当前键盘固件提供的接口。

## 本地运行

1. 解压或克隆本项目。
2. 双击 `start-local.bat`。
3. 使用桌面版 Chrome 或 Edge 打开脚本显示的 localhost 地址。
4. 关闭 QK 官方配置页面，避免两个页面同时占用设备 HID/串口。
5. 点击“连接 HID”；上传彩色屏幕素材或 7×7 点阵动画时再连接 CDC。

也可以在 PowerShell 中运行：

```powershell
.\start-local.ps1
```

## RGB 使用方法

1. 打开“主键盘逐键 RGB 画板”。
2. 选择颜色并点击或拖动键帽。
3. 使用“整帧填充”快速设置背景。
4. 新增或复制帧制作动画。
5. 点击“发送当前帧到键盘（RAM）”发送静态画面。
6. 选择“4 FPS（稳定高速，推荐）”后点击“实时播放到键盘”。
7. 结束时点击“退出接管 / 恢复官方灯效”。

“自定义效果生成器”支持先点击“开始选择效果按键”，再在键盘图上选择一个或多个键。未选择时作用于全键盘；选中后，生成帧和顺滑播放都只改变这些键。宽键会自动选择其全部物理灯。

“生成并替换动画帧”保留可编辑的普通 RGB 帧。“顺滑播放选中键”使用 V3 单包命令，以目标 30 FPS 让所选键呼吸或在两种颜色间连续渐变；未选中键维持原来的颜色。

网页关闭后顺滑动画仍会停止并恢复官方灯效，因为动画计时仍在浏览器端；本版本的改进重点是把每帧从 15 包缩减为 1 包。完全脱离网页运行的效果仍需要后续在 PLC 中加入本地计时器和配置状态。

## 彩色屏幕使用方法

1. 打开“彩色屏幕”，连接 CDC。
2. 选择图片、GIF / MP4，或导入多张图片作为相册。
3. 选择“自定义槽”或“当前主题槽”，并设置缩放、视频采样帧率或相册切换方式。
4. 点击“处理并保存到键盘”，确认覆盖目标槽。

屏幕素材会在浏览器本地转为 QK80 MK2 使用的 320×172 RGB565 文件，再通过 `E0/E1/E2` 写入键盘本地存储。保存完成后可关闭网页，屏幕内容仍由键盘独立播放。自定义动画最多 500 帧、主题动画最多 300 帧；较长视频可降低采样帧率或先裁短。

## 安全说明

- RGB 自定义帧不会调用 `CUSTOM_SAVE`，不会写入 EEPROM。
- 静态帧使用 50 ms 安全包间隔。
- 实时 4 FPS 使用实机验证过的 10 ms 包间隔。
- 传输错误时网页会自动尝试发送 EXIT。
- 如果 HID 完全无响应，可拔插 USB 恢复官方灯效。
- EEPROM Reset、设备绑定清除等功能仍属于持久化操作，请确认后再使用。
- 彩色屏幕上传会覆盖所选的自定义槽或主题槽，属于持久化写入；上传前网页会再次确认。

## 已验证结果

- 91/91 灯映射完成
- RGB 红、绿、蓝通道正确，无串色
- 全黑整帧无残留
- COMMIT 原子刷新
- 错误 sequence 不改变物理画面，新 session 可恢复
- EXIT、页面关闭、刷新和重新上电均可恢复官方灯效
- 10 ms 档冷启动立即播放，实际 4 FPS，超周期帧 0
